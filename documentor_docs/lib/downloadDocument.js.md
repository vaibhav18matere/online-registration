# Documentation Guide for `lib/downloadDocument.js`

This document provides a detailed explanation of the `lib/downloadDocument.js` file, which contains functions for downloading documents from a given URL and generating a safe file name based on a provided label.

## Overview

The `lib/downloadDocument.js` file exports two functions:

1. `getFileNameFromUrl(url, label)`: Generates a safe file name from a URL and a label.
2. `downloadDocument(url, label)`: Downloads a document from a specified URL and saves it with a generated file name.

## Functions

### 1. `getFileNameFromUrl(url, label)`

#### Purpose

The `getFileNameFromUrl` function is designed to create a safe and valid file name using a URL and a label. It extracts the file extension from the URL and sanitizes the label to ensure it is suitable for use as a file name.

#### Parameters

- `url` (string): The URL from which the file extension is extracted.
- `label` (string): The label used to generate the file name.

#### Returns

- A string representing the safe file name, which includes the sanitized label and the file extension.

#### How It Works

1. **Extract URL Path**: The function splits the URL at the `?` character to remove any query parameters, focusing only on the path.
2. **Match File Extension**: It uses a regular expression to match the file extension at the end of the URL path. If no extension is found, it defaults to `"file"`.
3. **Sanitize Label**: The label is sanitized by replacing any non-alphanumeric characters (except hyphens and underscores) with hyphens. Leading and trailing hyphens are also removed.
4. **Return File Name**: The function returns a string combining the sanitized label and the file extension.

### 2. `downloadDocument(url, label)`

#### Purpose

The `downloadDocument` function is responsible for downloading a document from a given URL and saving it locally with a file name generated by the `getFileNameFromUrl` function.

#### Parameters

- `url` (string): The URL from which the document is to be downloaded.
- `label` (string): The label used to generate the file name for the downloaded document.

#### How It Works

1. **Fetch Document**: The function uses the `fetch` API to request the document from the specified URL.
2. **Check Response**: It checks if the response is successful (`response.ok`). If not, it throws an error indicating the download failed.
3. **Create Blob**: The response is converted into a `Blob` object.
4. **Generate Blob URL**: A temporary URL for the blob is created using `URL.createObjectURL`.
5. **Create Anchor Element**: An anchor (`<a>`) element is created and configured with the blob URL and the download attribute set to the file name generated by `getFileNameFromUrl`.
6. **Trigger Download**: The anchor element is appended to the document body, and a click event is programmatically triggered to start the download.
7. **Cleanup**: The anchor element is removed from the document body, and the blob URL is revoked using `URL.revokeObjectURL` to free up resources.

## Conclusion

The `lib/downloadDocument.js` file provides a straightforward mechanism for downloading documents from a URL and ensuring the file name is safe and descriptive. The two functions work together to handle file name generation and the download process efficiently.
